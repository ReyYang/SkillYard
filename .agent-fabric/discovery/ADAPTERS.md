# 本机连接说明

本目录说明如何记录已经由当前 Agent 发现并经用户选择的本机连接。它不是工具清单，也不限制未来可以接入的 Agent CLI、网页 Agent、浏览器、连接器或宿主原生能力。

## 原则

1. 当前 Agent 先使用可见的静态信息进行发现，并用普通语言向用户展示有证据支持的选项。
2. 运行帮助、版本、probe、登录或真实任务前，必须说明将执行的具体操作并取得相应许可。
3. 缺少外部工具时跳过并提示用户自行安装；不得自动安装、登录或修改全局配置。
4. `.agent-fabric/local/resolution.json` 是当前机器 Role 到协作者、模型和调用方式的唯一真值。
5. `.agent-fabric/local/adapters/` 只保存当前机器需要的连接说明，字段可以随真实工具能力扩展；不得把某一种连接方式升级为 Portable 规范。
6. 协作者不可用或配置变化时明确报告，禁止静默换成其他工具、模型或权限。

## 可选的本地兼容性说明

当某个命令行连接需要复现只读兼容性探测时，可以保存一个简单 JSON 文件：

```json
{
  "name": "本机协作者",
  "command": "/absolute/path/to/command",
  "probe": ["--help"],
  "notes": "只用于初始化或重新配置时确认这个连接仍可启动"
}
```

除 `command` 和 `probe` 外可以记录当前环境真正需要的信息。Rust 辅助程序不要求 Agent 的原始输出是 JSON，也不会把探测成功解释为日常协作已经通过。
