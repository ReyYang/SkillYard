# SkillYard Library 三主题 UI 规范

本文档把三张已确认参考图转换为可研发、可比较、可验收的前端规范。参考图是视觉事实，产品行为仍以现有 `InventoryPage`、统一 Bundle read model 和生命周期回调为准。

## 1. 视觉事实与验收视口

| Theme Preset | 参考图 |
| --- | --- |
| `Archive` | `docs/assets/theme-archive-reference.png` |
| `Layers` | `docs/assets/theme-layers-reference.png` |
| `Ledger` | `docs/assets/theme-ledger-reference.png` |

- 三张参考图原始尺寸均为 `1487 × 1058 px`，宽高比为 `1.4055`。
- `1180 × 840 CSS px` 是三套主题共享的设计坐标系，不是窗口硬限制。
- 实际窗口变化时，以 `min(窗口宽 / 1180, 窗口高 / 840)` 计算统一缩放比例；页面、浮层和 Agent 入口必须一起缩放，不能分别重排。
- 视觉 QA 必须在同一窗口尺寸、同一语言、同一 Bundle 数据和同一选中状态下比较。
- 验收目标是整体构图、主要区域比例、字体层级、间距、颜色和组件密度达到参考图的 `90%+` 视觉一致性。
- 页面不得出现横向文档滚动条；默认视口只允许主题主体区域在内容确实超长时纵向滚动，滚动条不作为常驻视觉元素。

## 2. 共享产品合同

三套主题共享：

- 同一份 Bundle 列表、选中 Bundle、搜索词、管理状态筛选和分类筛选；
- 同一套 `查看 Bundle`、安装、发现、项目、设置、更新、刷新、挂载、接管和删除回调；
- 同一个 Agent Session 和浮动入口；
- 同一组可访问名称、键盘选择行为和确认流程。

三套主题可以不同：

- 顶部导航的视觉结构；
- Bundle 列表的陈列方式；
- 当前 Bundle 详情的布局；
- 纯展示用的横向位置、层叠方式和装饰资产。

不得为任一主题复制领域状态、生命周期入口或持久化协议。

## 3. 共享基础 Token

### 字体

| 用途 | 字体栈 | 说明 |
| --- | --- | --- |
| 中文与 UI | `"SF Pro Text", "PingFang SC", -apple-system, BlinkMacSystemFont, sans-serif` | 导航、按钮、说明、表格 |
| 大号 UI 标题 | `"SF Pro Display", "PingFang SC", -apple-system, sans-serif` | Layers 标题、Ledger 列表标题 |
| 编辑式衬线标题 | `"New York", "Iowan Old Style", "Palatino Linotype", Georgia, serif` | Archive 标题、三主题字母 Monogram |
| 等宽路径 | `"SFMono-Regular", Menlo, monospace` | 仅详情页真实路径 |

### 通用尺寸

- 默认窗口：`1180 × 840`。
- 顶部导航交互高度：`38–44px`。
- 普通 UI 正文：`13–15px`，行高 `1.45–1.65`。
- 次要信息：`11–12px`。
- 主按钮圆角：`8–10px`；浮层圆角：`14–18px`。
- 键盘焦点：`2px` 主题色外轮廓，偏移 `2px`。
- 动画只用于 hover、选择和弹层，持续时间 `120–180ms`；遵守 `prefers-reduced-motion`。

## 8. 窗口缩放边界

- 三套主题始终使用同一个 `1180 × 840` 设计坐标系，窗口宽高变化时只做统一比例缩放。
- 不建立 `1080px`、`840px` 等会改变布局结构的断点；窄窗口不能切换成另一套导航、卡片或详情排列。
- 当窗口宽高比与设计坐标系不同时，主题背景填充剩余空间，主体居中；不能拉伸横向或纵向比例。
- `<760px` 不属于 1.1.0 的正式窗口范围；Tauri `minWidth` 继续限制为 `760px`。
- 内容超长时优先截断次要元数据、限制成员预览数量，并通过详情页查看完整内容；不得通过增加多个嵌套滚动面板解决。

## 9. 验收方法

每个主题都要完成：

1. 在 VM 中使用同一候选 `.app`、`1180 × 840` 窗口和简体中文。
2. 使用相同的五个 Bundle fixture 和相同选中项。
3. 截取应用内容区域，与对应参考图按相同宽高比并排。
4. 检查字体与字重、区域比例、间距、颜色、资产、文案和交互入口。
5. 有 P0、P1 或 P2 差异时继续修复；只有剩余 P3 才可通过。
