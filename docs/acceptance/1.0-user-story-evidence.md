# SkillYard 1.0 User Story 验收证据

本文把 [1.0 PRD](../prd/0001-skillyard-1.0.md) 中 167 条 User Story 逐条映射到可重复验收证据。它不重新定义产品，也不以文档描述代替运行结果。

## 证据类型

- `[AUTO]`：由自动化测试或静态契约检查验证，发布前执行 `pnpm test`、`pnpm build`、`cargo test --workspace`、`cargo clippy --workspace --all-targets -- -D warnings`。
- `[MAC-CONTRACT]`：必须在受支持平台使用真实发布候选、Supported App 路径或应用替换流程验证；正式发布候选还要进入干净的 Apple Silicon macOS VM。
- `[HUMAN]`：只判断文案是否容易理解或完整日常流程是否符合预期，不替代自动化正确性测试。

| `cargo test --workspace` | Rust 单元测试与公开 seam 集成测试全部通过；显式依赖本地 Codex 的契约单独执行。 |
| `cargo clippy --workspace --all-targets -- -D warnings` | 无 warning。 |

| `MAC-01` | VM 校验 SHA-256 后解压、移动到 Applications，并按正常 Gatekeeper 路径首次启动；架构、最低系统版本和 ad-hoc signing 均符合发布边界。 |
