# Project skills are project-scope Exposures

Project-level skills are not a separate kind of Library Entry. They are Exposures with scope `project` and a recorded `projectRoot`. The same Library Entry can be exposed to user scope and to one or more project scopes across supported Hosts.

When SkillYard finds an existing project skill entry that it does not manage, doctor reports it as an Unmanaged Host Entry. The user can keep it unmanaged, import it into the Library, or replace it with a managed Exposure.
