# AI Assist is optional and can help infer unknown provenance

SkillYard's core workflows will be deterministic and must not require AI. Source Trees, Library Entries, Exposures, doctor checks, Update Impact, Plan, and Apply should work from local files, Git, SQLite, and Host Adapters.

AI Assist may be used explicitly for explanation and investigation, including unknown skill provenance. When a skill's origin is unclear, AI Assist can compare local content, metadata, filenames, and public sources to suggest likely origins with evidence and confidence. These suggestions are Provenance Inference, not confirmed provenance, until the user accepts or corrects them.
