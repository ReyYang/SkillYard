# First-version command surface

The first version will focus on six commands: `init`, `import`, `expose`, `doctor`, `update`, and `serve`. This keeps the product centered on setting up the Library, bringing skills in, exposing them to Hosts, checking health, previewing updates, and opening the Local Server. Commands such as remove, rename, export, security scan, and publish can come later after the core Source Tree and Exposure flow is stable.
