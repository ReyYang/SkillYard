# SkillYard 1.0.1

SkillYard 1.0.1 修复了单个损坏 Skill 导致整个扫描流程失败的问题。

## 修复内容

- 单个损坏或断开的 Skill 不再阻止首次扫描完成。
- 同一目录中的其他正常 Skill 仍会被发现和刷新。
- 扫描告警按具体 Skill 路径分别展示和保存。
- 修复某个 Skill 后，对应告警会独立消失，不影响其他仍有问题的条目。

## 官方下载

SkillYard 唯一的官方下载渠道是本仓库的 [GitHub Releases](https://github.com/ReyYang/SkillYard/releases)。请不要从第三方镜像下载应用。

本次 Release 包含：

- `SkillYard-1.0.1-macos-aarch64.zip`

## 系统要求

- macOS 14 或更高版本
- Apple Silicon Mac
- Supported Apps：Codex、Claude Code、GitHub Copilot

Intel Mac、Windows 和 Linux 当前不受支持。

## 安装与 Gatekeeper

1. 下载 ZIP。
2. 解压 ZIP，将 `SkillYard.app` 移动到 `/Applications`。
3. 首次打开应用。

SkillYard 1.0.1 使用 ad-hoc signing，尚未经过 Apple notarization。首次打开时，macOS Gatekeeper 可能要求按系统提供的正常用户路径确认后再启动。请不要运行来源不明的绕过脚本。
