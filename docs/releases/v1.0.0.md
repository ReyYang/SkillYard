# SkillYard 1.0.0

SkillYard 是一款本地优先的 macOS 应用，用于集中管理 Agent Skills 的安装、挂载、更新、接管和移除。

## 官方下载

SkillYard 唯一的官方下载渠道是本仓库的 [GitHub Releases](https://github.com/ReyYang/SkillYard/releases)。请不要从第三方镜像下载应用。

本次 Release 包含：

- `SkillYard-1.0.0-macos-aarch64.zip`

## 系统要求

- macOS 14 或更高版本
- Apple Silicon Mac
- Supported Apps：Codex、Claude Code、GitHub Copilot

Intel Mac、Windows 和 Linux 当前不受支持。

## 安装与 Gatekeeper

1. 下载 ZIP。
2. 解压 ZIP，将 `SkillYard.app` 移动到 `/Applications`。
3. 首次打开应用。

SkillYard 1.0.0 使用 ad-hoc signing，尚未经过 Apple notarization。首次打开时，macOS Gatekeeper 可能要求按系统提供的正常用户路径确认后再启动。请不要运行来源不明的绕过脚本。
